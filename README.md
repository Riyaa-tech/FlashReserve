# FlashReserve

FlashReserve is a high-concurrency booking and inventory management platform designed to handle simultaneous booking requests reliably and prevent overselling.

## Project Goals

- Handle concurrent booking requests safely.
- Maintain accurate inventory during high traffic.
- Provide REST APIs for booking and inventory management.
- Use a relational database for persistent storage.
- Implement asynchronous processing for background tasks.
- Containerize application components with Docker.
- Deploy a scalable, secure architecture on AWS.

## Planned Technology Stack

- **Backend:** Java 21, Spring Boot, Maven
- **Frontend:** React, JavaScript
- **Database:** PostgreSQL
- **Containerization:** Docker, Docker Compose
- **Cloud Infrastructure:** AWS
- **Version Control:** Git, GitHub

## Project Structure

- `backend/` — Java Spring Boot application
- `frontend/` — React frontend
- `infrastructure/` — Docker and infrastructure configuration
